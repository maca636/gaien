# 外苑エリア イベント・天気情報

神宮外苑エリア4施設のイベント・天気・外苑前駅の混雑予測を1画面にまとめた、受付スタッフ用ダッシュボード。

公開URL: https://maca636.github.io/gaien/

1920×1080固定・スクロールなしの単一画面レイアウト。iPad/デスクトップから「ホーム画面に追加」「アプリとしてインストール」してすぐ開けるよう、`manifest.webmanifest` と各サイズのアイコン（`icons/`）を用意している。

## 仕組み

- **天気** … ブラウザから [Open-Meteo](https://open-meteo.com/) を直接取得。開いた時＋1時間ごとに自動更新。
- **イベント** … `events.json` を読み込んで表示するだけ。ページ自体は完全に静的。
- **外苑前駅の混雑予測** … `events.json` の各イベント開始時刻に、施設カテゴリごとの想定所要時間（野球3.5h／サッカー等2h／ラグビー2h／公演2.5h）を足した終了予定時刻をもとに、時間帯ごとの重なりをブラウザ側で計算して表示。あくまで推定。
- `events.json` は毎朝、スケジュール実行の Claude Code エージェント（クラウド）が
  Web検索で4施設の当日イベントを確認して更新・commit する。
  ルーティン: https://claude.ai/code/routines

## events.json の形式

各施設キーの値は「その日のイベントの配列」。1施設に複数イベントがある日（大学野球の第1・第2試合、対抗戦の複数カードなど）を素直に表現するため、単一オブジェクトではなく配列にしている。

```json
{
  "jingu": [
    { "time": "11:00", "name": "東京六大学野球 秋季リーグ開幕", "sub": "慶應義塾大学 vs 東京大学" },
    { "time": "14:00", "name": "東京六大学野球 秋季リーグ開幕", "sub": "早稲田大学 vs 法政大学" }
  ],
  "kokuritsu": [],
  "rugby": [],
  "hall": [],
  "alert":   "混雑注意などの一言（無ければ空文字）",
  "updated": "2026-09-10T05:30:00+09:00"
}
```

- 配列が空 `[]` ならその施設は「本日のイベントはありません」と表示。
- `time` は `HH:MM`。分からなければ空文字 `""`（誤情報より空欄の方がよい）。
- `sub` は対戦カードや開場時刻などの補足。無ければ省略可。
  - 対戦カードの場合は必ず半角スペース区切りの `"チームA vs チームB"` 形式にする（画面側がこの `" vs "` を検出して対戦相手を大きく表示する）。開場時刻など対戦カードでない補足はこの形式にしない。
- 1施設あたり3件程度まで想定（それ以上は主要なものに絞る）。
